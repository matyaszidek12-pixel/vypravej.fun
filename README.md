# Vyprávěj — fanouškovský web
Statický web pro GitHub Pages.

## Nasazení
Nahraj obsah této složky do kořene repozitáře `vypravej.fun` a ponech strukturu složek `css/` a `js/`.

## Poznámka
Tato první verze používá ověřené údaje a odkazy z veřejných stránek České televize. Epizodová databáze je připravena k rozšíření na všech 123 přehratelných dílů.
